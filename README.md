A one-line, one-star review of Monday written as if Monday were a restaurant: the menu is alarms and emails, the waiter never shows, and the bill runs five days long. Entry for the [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61) bounty on make.fun.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-star-for-monday-test node main.ts
cat /tmp/one-star-for-monday-test/entry.txt
```

The program writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
